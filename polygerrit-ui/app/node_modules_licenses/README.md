# Licenses for node modules

This folder contains information about licenses for modules from node_modules folder.
It must contains licenses for all modules/files which content is included in fully or partially in
the final build artifact.

If a module is used only for development, license information can be skipped from this folder.
License checker will fail if you are using code from this module for production.

#Directory layout
The license.json file must be placed at the same relative path as package.json file in node_modules.

The `default-license.json` contains is used if there is no license for a node module.

The `add_missing_license.sh` add missing license.json files for modules by copying default-license.json.

The yarn-lock.sha256 contains sha256 for the yarn.lock file and must be placed on top level.

#license.json format
The `license.json` have the following data:
```
{
  "default": {
    //mandatory block, default license for all files in the module.

    //licenseType are used by license checker.
    "licenseType": short name of license type ("MIT", "BSD-3-Clause", etc...),

    //Ths licenseSource is used to produce document with all used licenses 
    "licenseSource": {...} //Information about location of the license text - see below
  },
  "exceptions": [
    //optional - you can set specific licenses for some files or directories in the module
    {    
        "paths": [..strings..], //files and/or directories - relative to the module root folder. 
        "license": {
            //Same format as "default" block
        }   
    }    
  ]
}
```

 The special `DO-NOT-DISTRUBUTE` licenseType can be used to mark some modules/files as not
 appropriate for final production. Use it only if you don't know exact license type or if licenseType
 is appropriate for gerrit, but you want to avoid content of a module/file/directory in the production.
 
 LicenseSource is mandatory only if the licenseType are approprite for final production. 
 
 License source can be:
 - A file of a module:
 ```
    "licenseSource": {
      "packageFile": "LICENSE.txt" //Path relative to then module root.
      "comment": "..." //Optional - additional comment about licenses. This information doesn't use
    }
```

- A file placed near licenses.json in node_modules_licenses folder:
```
    "licenseSource": {
      "localFile": "LICENSE.txt" //Path relative to the license.json file.
      "comment": "..." //Optional - additional comment about licenses. This information doesn't use
    }
```

- A file placed in node_modules_licenses folder:
```
    "licenseSource": {
      "sharedFile": "LICENSE.txt" //Path relative to the node_modules_licenses folder.
      "comment": "..." //Optional - additional comment about licenses. This information doesn't use
    }
```
